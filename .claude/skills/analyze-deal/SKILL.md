# Аналитический разбор (analytics)

Цель: нанять ИИ-аналитика, оценить фин-модель и бизнес компании, выдать сбалансированный разбор + PDF, прикрепить к карточке проекта.

## Процедура
1. **Извлеки данные** из материалов: PDF читай напрямую (Read), XLSX — через пакет `xlsx` (`node -e`), текст из чата — парси «Условия сделки».
2. **Найми аналитика** (Agent, general-purpose, можно несколько параллельно по компаниям). Промпт: «старший инвестиционный аналитик, сбалансированно, можно веб-сёрчить пиров». Верни СТРОГО JSON:
   `{rating, ratingScore(1-10), thesis, execSummary, businessModel, financialsSummary, metrics[[label,value]], valuationSummary, entryMultiple, peerNote, scenarioView, keyDrivers[], risks[], verdict}`.
   Особо оцени: справедливость оценки vs пиры, премию входа, реализм сценариев. Числа не выдумывать.
3. **Добавь JSON** в `prisma/analyses.json` (ключ = точное имя проекта в БД). При новой компании — добавь её slug в `SLUG` в `prisma/gen-analysis.cjs`.
4. **Сгенерь PDF + запиши в БД:** `node prisma/gen-analysis.cjs` → PDF (графики сценариев и вход→выход, кириллица через Arial) в `public/uploads/analysis/`, пишет `Project.financialAnalysis` + `ProjectDocument(kind="analysis")`.
5. Секция «Аналитический разбор» на странице проекта (`src/app/project/[id]/page.tsx`) подхватит автоматически (рейтинг, тезис, резюме, драйверы/риски + скачать PDF).
6. **`/ship`**.

Всегда: разбор сбалансированный (не продажный), с дисклеймером «не ИИР».
