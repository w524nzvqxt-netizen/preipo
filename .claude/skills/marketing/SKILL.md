# Маркетинг (marketing)

## Вертикальные шортсы 9:16
1. **Сценарий** по `docs/SHORTS.md` (10 готовых сценариев): хук (0-2с) → проблема → решение → цифры (вход→выход, ×N) → CTA. 6-8 коротких сцен, дерзкий ритм.
2. **Озвучка HeyGen** (голос Dmitry, `HEYGEN_API_KEY`) по сценам → извлечь аудио ffmpeg (паттерн `remotion/gen-deal-audio.cjs`).
3. **Клипы Higgsfield** (MCP `hig`, `seedance_2_0`, **вертикаль 9:16**) — уникальные под сцены, не зацикливать.
4. **Рендер:** `npx tsx remotion/render-short.ts` (композиция `Short`, 1080×1920) → `public/uploads/shorts/`.

## Соцпосты и реклама
- **Telegram/X пост:** хук-заголовок + 3-4 факта/цифры (GMV, ARR, оценка) + вход→выход ×N + срок IPO + дисклеймер + CTA. По-русски, ёмко, без канцелярита.
- **Ad-копи:** цепляющий заголовок + 3 буллета выгоды + оффер (минимальный чек / «оставьте заявку»).
- **Заголовки для витрины:** премиально и понятно, в духе бренда.

## Правила
- Каждый материал — с **дисклеймером**: «не является индивидуальной инвестиционной рекомендацией, инвестиции в pre-IPO высокорисковые».
- Факты — только проверенные (гуглить актуальные оценки). Цифры из материалов сделки.
- Тон бренда: дорого, уверенно, по делу.
