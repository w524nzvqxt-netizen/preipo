# Добавление новой компании — оркестр

Цель: от «вот файлы про компанию» до живой карточки (и при желании — видео) за минимум шагов.

## Что прислать
Достаточно любого из:
- **Меморандум / тизер** (PDF) — основной источник параметров и тезисов.
- **Return Calculator** (XLSX) — точные числа: вход EV, цена за акцию, IRR, CoC, сценарии.
- **Текст из чата** (как описание сделки) — тоже годится.
- *(опц.)* **логотип** (SVG/PNG) — положу в `public/uploads/`, пропишу `logoUrl`.
- Скажи: **открытый раунд** (можно войти) или **закрытая сделка** (трек-рекорд).

## Что делаю я (пайплайн)

### 1. Извлечение
- PDF — читаю напрямую (Read).
- XLSX — выдёргиваю числа: `node -e` + пакет `xlsx` (см. как делали с Return Calculator'ами).
- Текст — парсю «Условия сделки / Параметры участия».

### 2. Проверка фактов + генерация контента (воркфлоу)
Запускаю сохранённый воркфлоу **`add-company`** (агенты):
- **Факты** — веб-проверка актуальной оценки / последнего раунда / ожиданий IPO.
- **Контент** — описание, 4 сейлз-поинта, плюсы, риски, 3 сценария ($100k), числа.
→ на выходе готовый JSON сделки.

Вызов: `Workflow({ name: "add-company", args: { name, sector, dealStatus, sourceText } })`.

### 3. Карточка в БД (одна команда)
Сохраняю JSON и выполняю:
```
node prisma/add-deal.cjs deal.json
```
Идемпотентно: повторный запуск обновляет карточку, а не плодит дубли.

### 4. Деплой
`npm run build` (проверка) → `git commit` → `git push` → Railway сам пересоберёт.
Карточка появляется на главной (в «Открытых раундах» или «Закрытых раундах»).

### 5. Видео (опционально, дольше)
Пайплайн уже есть (см. `CLAUDE.md`):
- **Клипы**: MCP `hig` (Higgsfield, `seedance_2_0`) — уникальные, не зацикливать.
- **Озвучка**: HeyGen (`HEYGEN_API_KEY`, голос Dmitry) → извлекаю аудио (ffmpeg-static).
- **Сборка**: Remotion — `npx tsx remotion/render.ts` (видео о компании, 16:9) / `render-short.ts` (шортсы 9:16).
- Готовый mp4 кладу в `public/uploads/`, в карточке ставлю `videoUrl` + `videoStatus=completed`.

## Контракт данных (JSON сделки)
Полная схема и значения по умолчанию — в шапке `prisma/add-deal.cjs`. Кратко:
```json
{
  "name": "...", "sector": "...", "dealStatus": "open|closed",
  "description": "...", "salesPoints": ["..."], "pros": ["..."], "risks": ["..."],
  "valuation": 0, "exitValuation": 0, "cocMultiple": 0, "expectedReturn": 0,
  "expectedExit": "1H 2028 · IPO", "pricePerShare": null, "volume": 0,
  "currency": "USD", "isHot": false,
  "scenarios": [
    {"key":"Худший","color":"amber","mult":1.5,"irr":"~19%"},
    {"key":"Базовый","color":"sky","mult":2.5,"irr":"~49%"},
    {"key":"Лучший","color":"emerald","mult":4.1,"irr":"~90%"}
  ]
}
```
Если `scenarios` не задать — соберутся из `cocMultiple`. `val` сценариев считается из `mult` на $100k.
